# Changelog

All notable changes to the People Work plugin are documented here. The plugin
uses [Semantic Versioning](https://semver.org/) independently of the People Work
application.

## 1.0.0 - 2026-08-30

### Added

- Initial cross-platform People Work plugin for Codex and Claude Code.
- Shared MCP configuration that starts the installed application with
  `people mcp`.
- Platform-neutral People Work icon and marketplace metadata.
